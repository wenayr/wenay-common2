# 2.4.0

- Add the internal dynamic-runtime slice: inert manifest validation, content-hash/signature/policy
  verification with brand-checked verified artifacts, `worker_threads` isolation with handshake,
  heartbeat, budgets and idempotent termination, and a host that stages, warms, health-checks,
  atomically activates and rolls back a slot through the existing Contract runtime. Stable leased
  handles keep the call path short; dependency brokering covers A -> B -> C with optional typed
  degradation for D. Nothing is exported and no public surface changed.
- Add the scoped `context.mcp` contribution registrar inside the worker plus a host-owned gateway
  that owns layered catalogs, namespaces, authorization and cleanup. Registrations are compared
  against an exact host policy, a staged candidate keeps its tools private, activation replaces the
  catalog alias, and a retired generation stops resolving instead of serving stale handlers.
- Add an external reference control plane under `experiments/dynamic-runtime`: immutable
  Git-provenance publication, content-addressed single-flight delivery, restart-safe desired
  state/receipts/audit/last-known-good over `ReplayStorage`, and fenced three-node canary rollout
  with probes, quarantine and automatic rollback.
- Add `doc/DYNAMIC-RUNTIME.md` as the canonical architecture page plus implementation prompts, and
  make it a non-negotiable rule in `CLAUDE.md`/`AGENTS.md` for runtime loading, activation,
  rollback and control adapters.
- Add `doc/prompts/IMPLEMENT-AGENT-HTTP-CONTROL.md` and two self-verifying examples for
  agent-facing control over plain HTTP, with no MCP SDK involved. `experiment:agent-control` proves
  the development loop: a completed file save stages, verifies and activates a new module version,
  a method added in the editor is listed and callable with no registration, a broken edit leaves
  the active generation answering, and rollback restores the previous binding as a new generation.
  `experiment:dynamic-tools` proves the heavier declared-tool path for published surfaces.
- Measure the slow-network transport questions left open by the July stands
  (`experiments/slow-network-2026-08`). A metered TCP relay shows `perMessageDeflate` removing
  12.6x wire bytes on rows-shaped JSON for about 2x CPU, which converts to 4.8-8.2x faster delivery
  at 1 Mbit/s, and reproduces the disconnect/reconnect cycle: one frame occupying the link longer
  than the heartbeat budget starves the ping. Raising `pingTimeout` or compressing the frame each
  prevent it independently.
- Record the resulting slow-network Socket.IO profile in `doc/RECOMMENDATIONS.md`, replace the
  unmeasured compression caveat with the measured result, and note that keyframe chunking is now
  the structural fix for reconnect storms rather than only a scaling follow-up.
- Extend the publish gate with `test:dynamic-runtime` and add a `test:dynamic-runtime:acceptance`
  sweep over the contract, reconnect, chaos, offline-store and replica-set oracles.
