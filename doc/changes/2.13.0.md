# 2.13.0

Five latent defects found by audit, each shipped only after a test that fails without the fix.

- **A server without `gate` stays callable after a refused reauth.** `RpcServerAuth` documents
  `ack.ok === false` as a refusal that does not throw, and Rule 6 promises the live session keeps
  its principal. `applyGrant` wrote `authed = authAck?.ok !== false` unconditionally, so one
  refusal answered every later CALL and PIPE with `E_UNAUTHORIZED` — permanently — while
  `downgradePrincipal`, the other half of the same corridor, had always read the gate correctly.
  Reachable only on a server that both uses `resolveAuth` and omits `gate`.
- **An async `onInvalid` that rejects no longer reaches Node's unhandled-rejection path.** The
  hook is typed `void | Promise<void>` and fires on malformed input from the wire, so a rejected
  telemetry call was a promise created by a remote peer. The CAPS branch already awaited; the
  request branch dropped the promise. Reachable only where the hook is installed and async.
- **A failed offline write no longer discards the snapshot.** `dirty` was cleared before the
  await, so on failure the retry in `finally` saw a clean flag and armed nothing; the snapshot
  waited for the next mutation, which for a quiet store never comes.
- **A store key named `__proto__` survives the lazy line.** The chunk object was a plain literal,
  so assigning that key replaced its prototype and `Object.keys` never saw it again — the key was
  neither transferred nor reported missing. The host now builds chunks with a null prototype, and
  the mirror takes the slower `defineProperty` path for that one name only, leaving the hot path
  on plain assignment.
- **An overtaken audio `start()` releases its own grant.** `stop()` runs synchronously before the
  await on `getUserMedia`, so it cannot cancel a start that has not resolved: both grants landed,
  the second overwrote the shared fields, and the first `MediaStream` was never stopped — the
  recording indicator stayed lit and its worklet kept pushing PCM into the same shell. The video
  source has carried this guard all along; audio now has it at both await points.

Proof, not assertion: `oracle/regression/critical-fixes.spec.ts`,
`oracle/realsocket/auth-ungated.spec.ts` and `oracle/realsocket/invalid-hook.spec.ts` were each
run against the unfixed code first and fail there — `Unauthorized` on every call, three unhandled
rejections, `snapshot=undefined`, a missing key, an unreleased stream. Two further audit findings
(flow streams surviving a transport teardown, and the mesh remembering a packet it rejected) are
real by reading but could not be reproduced without negotiating `CB_FLOW` or overflowing a route
with a live alternate, so they are NOT in this release.
