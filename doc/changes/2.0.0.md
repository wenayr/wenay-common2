# 2.0.0

- Make Store Replay V2 the only Store replay wire and expose its facade directly at `replay`.
- Remove Store batch v1/v3-v7 codecs, compatibility members, diagnostics and benchmarks.
- Remove RPB/1, RPB/2 and RPB/3 completely, including binary negotiation, schema codecs and benchmarks, after benchmarks showed that the binary path underperformed the JSON wire and did not justify its complexity.
- Remove the unused `msgpackr` dependency. JSON arrays are the sole RPC application wire.
- Remove the legacy Store replay line, optional batch negotiation and persisted legacy coordinates.
- Keep the independent peer relay patch protocol unchanged; it is not Store Replay.
- Remove stale binary/legacy guidance, completed planning documents and the demo's old-server emulation; keep the stand focused on the current JSON RPC and Store Replay V2 surfaces.
