# 1.0.86

- Add `createStoreFollower` to Observe: a server-side mirror instance — `syncStoreReplay` into a local store plus a cascading `exposeStoreReplay` over it, with a reactive upstream status store (`{upstream, seq, epoch, error}`); additive `onLive` hook in `replaySubscribe` (fires after every successful catch-up).
- Add manual failover: `follower.promote()` stops mirroring, bumps the line epoch and keeps the cascade journal alive — subscribers of the node survive the role change without a re-keyframe; `diffKeyedState` records the split-brain tail on rejoin (re-apply candidates, keyframe material, preserved conflict pairs).
- Add safe artifact transfer: `sha256Hex` content-hash versions, `createArtifactByteCache` (single-flight fetch behind an sha256 integrity gate, LRU byte budget) and `createArtifactMirror` (read edge over a replicated catalog with the same `{state, open, revoke}` fragment shape as the host).
- Demo: `DEMO_MIRROR_OF` mirror mode and `npm run demo:mirror` — mirrored workboard with forwarded commands (through receipts), replicated artifact catalog with lazy hash-verified bytes served from each node's own sandbox origin, instance badge with role/epoch, a promote button for manual failover, and rejoining the old node as a mirror of the promoted leader.
- Oracles over real sockets: store-mirror (15 checks), artifact-mirror (11), store-promote (16); full suite 62/62. Public API of existing modules unchanged (additions only).
