# 2.21.2

- Fix Observe parent replacement with retained nested reactive objects/arrays. Shallow
  unwrapping previously let `rebind` install a node's own proxy as its target, causing
  recursive property reads or `ownKeys`/`snapshot()` and a stack overflow.
- Normalize the incoming plain data graph before any destination path is rebound,
  including property definitions, initial Store input and whole-root sibling swaps.
  Preserve raw value identity, path proxy identity, subscriptions and descriptors;
  avoid creating lazy child proxies while preparing input. Eager initialization is
  cycle-aware. Public exports and signatures are unchanged.
- Refuse immutable data slots containing proxies with a descriptive `TypeError`
  before mutation; document `cloneStoreValue` as the explicit detached-input option
  and clarify path identity versus entity identity and local versus replicated aliases.
- Add pre-fix reproductions plus primitive/composition regressions for repeated
  parent replacement, bounded history, array replacement, deep inputs, notifications,
  branch moves/swaps, patch/replay delivery and snapshot restoration. Verify the
  regression suite again through the installed public `/observe` entrypoint.
