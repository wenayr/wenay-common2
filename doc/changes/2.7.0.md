# 2.7.0

Two additive capabilities and two lazy-line hardenings. No behavior changes without the new
options.

- **Static key selection on the lazy line.** `exposeStoreLazyLine(store, {keys})` publishes only
  the selected top-level keys: changes outside the selection cost nothing — no clone, no revision
  bump, no re-send on catch-up. The cursor gains `selectionId` (same identity hash the replay view
  uses, now shared in `store-selection.ts`); a cursor issued for a different key set is refused as
  `stale` and the subscriber reconciles by a full pass + sweep, exactly like a lifetime change.
  Several lines — full and per-partition selections — coexist on one authoritative Store without
  cursor bleed. Host `view` now exposes `{lineId, selectionId, keys(), snapshot()}`.
- **Opt-in byte budget for the fs replay journal.** `openFsReplayStorage(file, {maxBytes})` keeps
  the JSONL log near the budget by pruning at a keyframe boundary to ~3/4 of it, keeping the
  longest suffix that fits — the budget buys "how long can a client be away and still get its
  exact tail". A reader older than the cut gets a keyframe reset, which is the wire semantics an
  evicted seq already had. The lossless floor [latest keyframe + tail] is never cut into;
  `size().overBudget` reports it instead. Absent `maxBytes` = append-only forever, bit-for-bit the
  old behavior: a disk budget must be asked for, never assumed.
- **Lazy line: keys present before the line attached can now be tombstoned by a root swap.** The
  line serves pre-existing keys from state but never tracked them, so a whole-root replacement
  patch (path `[]`, from a custom patch source — the Store engine itself decomposes `replace()`
  into per-key deletes) could not prove they were gone and a mirror kept them forever. Keys present
  at attach are registered at revision 0, and the root-swap branch now tombstones every known key
  the new root no longer has.
- **Lazy line: tombstones expire on read too.** Expiry only ran on writes, so a store that stopped
  changing retained every tombstone indefinitely. A read is the only guaranteed activity on a
  quiet line and now prunes as well.
