# 3.0.0

Major release: the package sheds what does not belong to a transport/state library. Migration rows
are in [NAMING_RENAMES.md](../NAMING_RENAMES.md); nothing else in the API changed.

## Breaking

- Exchange data moved to the separate package `wenay-exchange` (1.0.0) with the same names:
  `Bars` and the flat bars/history/market-data names (`CQuotesHistory*`, `CBar*`, `OHLC`,
  `CTimeSeries*`, `createRandomBars`, `LoadQuoteBase`...). Replace the import source:
  `import {Bars, CQuotesHistory} from 'wenay-exchange'`. It uses this package as a peer
  dependency, so a project keeps one copy and one `TF` identity (`Bars.TF === TF`).
  `TF`, `Period`, the time API and the generic `Params` / `CParams` model stay here.
- No mandatory dependency any more. `express` and `@types/express` are optional peers: install
  them for `server`, `server/webhook`, `server/blob`, `service/server`, `service/host`
  (and `@types/express` for the types of `server/http`). Root, `client` and the narrow entries
  never needed them; a core-only project now downloads nothing else.
- axios is gone. The webhook client and the Caddy download use the platform `fetch` through an
  internal request primitive that still rejects on a non-2xx status and aborts on timeout.
  `createWebhookClient(...).status(tag)` returns `{status, data: {subscribed, expireAt?}}`
  instead of the whole `AxiosResponse`; rejections are `HttpStatusError` (`status`, `method`,
  `url`) instead of `AxiosError`.
- The `wenay-common2/lib/client` and `wenay-common2/lib/server` export aliases are removed; use
  `wenay-common2/client` and `wenay-common2/server`.

## Package and release

- The npm package ships the library, docs and the runnable `examples/` only: `oracle/`,
  `observe/`, `replay/` and `demo/` import the repository's `src/` and stay in the repository
  (unpacked 5.6 MB → 3.3 MB). Shipped docs name those as plain repository paths; the doc-link
  check now fails when a shipped doc links to an unshipped file.
- Releases go through `scripts/release-guard.mjs`: `release:verify` records the verified tree,
  `npm run publish` refuses unless that exact tree is committed and pushed, then tags `v<version>`.
- The `hosting` example declares `express` (it relied on the old transitive dependency).

## Verification

`npm run release:verify`: build, `npm test` (including the release-guard spec and the
`wenay-exchange` specs), all oracles (new: `http-request`, `webhook3` — written first against
the axios implementation), separate-process failover, the isolated tarball consumer with
explicit server peers, the `wenay-exchange` consumer (both tarballs, no nested core copy, no
express/axios/socket.io installed, strict declarations), the scaffold and every example from
the installed tarball. A runtime export diff against the published 2.21.3 shows only the
exchange names and the two aliases removed.
