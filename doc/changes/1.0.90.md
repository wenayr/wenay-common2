# 1.0.90

- Add `Peer.createPeerPacketOffers` and `Peer.createPeerPacketMesh`: reusable connection offers, direct and multi-hop packet routing, group routing, path scoring, loop/TTL protection, reconnects and fallback, with deterministic tests and an interactive Lab stand.
- Add an unpaced MAX video mode that preserves the selected source and resolution, removes the artificial frame-attempt limit, and reports actual capture, encode and delivery throughput.
- Forward RPC Listen `{current: true}` across the wire, including deduplicated current delivery for late subscribers and safe synchronous `once` cleanup, covered by replay and real Socket.IO oracles.
- Update the brief and rare public docs and reduce the roadmap to genuinely conditional follow-ups, removing completed target plans.
