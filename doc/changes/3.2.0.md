# 3.2.0

MCP tools generated from a facade: one facade and one metadata set give RPC, HTTP, OpenAPI and MCP.
Additive; no wire-format change.

## New entry `wenay-common2/server/mcp`

- `createMcpFacadeServer({name, version, object, meta?, strict?, readOnly?, policy?, around?,
  formatResult?, limits?, names?, resources?, validator?})` walks a facade exactly like
  `createHttpFacadeServer` (one shared walk, `facadeWalk.ts`) and registers `tools/*` — and
  `resources/*` for Listen streams — on the official SDK's low-level `Server` (`control.attach`
  accepts `Server` or `McpServer`, `control.server()` creates one). `@modelcontextprotocol/sdk`
  ^1.30 is an optional peer loaded by this entry only.
- Metadata next to the code: `describeMethod(fn, {description, title?, input? | args?, output?,
  annotations?, context?})`, or a `meta` map by dotted path. `input` = one object argument, `args` =
  named positional arguments mapped to one object schema and back. `strict` refuses functions without
  description and schema (listing the paths) and stale `meta` keys; otherwise defaults are reported as
  findings.
- Tool names: path joined by `names.separator`; `'mcp'` or `'claude'` charset with an explicit refusal
  naming the path, or `names.map` to `_`; duplicates refused naming both paths.
- Policy: read-only server mode (unlisted and uncallable), `policy.readOnly(path)` fills
  `readOnlyHint`, `policy.concurrency(path)` `'serial'` (one ordered `createAsyncQueue(1)` per server,
  shared by derived principal facades) or `'parallel'`; `around(ctx, next)` middleware inside the
  queue slot for journaling/receipts/audit; `on.called` / `on.failed` audit streams.
- `context: true` adds `{signal, progress, session, principal}`: MCP cancellation aborts `signal`,
  progress tokens reach `progress`.
- Results: object → `structuredContent` + JSON text, primitives/arrays as `{value}`, the RPC walk codec
  for Date/Map/Set/RegExp/BigInt, top-level bytes as one blob resource, nested bytes refused, `RpcLimits`
  on input and output, input/output validated against their schemas; throws → `isError` with the
  `MyError` code and no stack.
- Listen `on` / Listen objects → resources with subscribe (coalesced per tick) and read (a
  `listenStore`'s current value); `policy.resource` exposes zero-argument views; `control.mount` /
  `replace` / `unmount` / `refresh` send `tools/list_changed` (and `resources/list_changed`).
- `createMcpFacadeHttp({app, path, mcp, mode?, maxSessions?, sessionTtlMs?, auth?})`: Streamable HTTP
  on the same Express app, stateful sessions (DELETE, idle TTL and `control.terminate` end a session;
  closing a transport does not; the limit is an explicit 503) or stateless; bearer auth mirrors RPC
  (`resolveAuth(token) -> {object, principal?, expiresAt?}`, one principal per session).
  `serveMcpStdio(mcp)` for stdio.
- Declarations reference only the SDK's `types.js` and `shared/transport.js`; servers and validators
  are typed structurally (`McpServerLike`, `McpJsonSchemaValidator`). The SDK's own CommonJS
  declarations of `Server`/`McpServer`/validators fail TS1541 under `skipLibCheck: false`
  (`dist/cjs/validation/types.d.ts`); the installed-package check compiles this entry that way.

## HTTP / OpenAPI

- `createHttpFacadeOpenApi` reads the same metadata (`meta?` option and `describeMethod` on the
  function): summary, description, tuple body and result schema. Explicit `summaries`/`argSchemas`
  still win. `describeMethod` / `methodMeta` are exported from `server/http` and `server` too.
- `createHttpFacadeServer` now runs on the shared walk; routes, errors and refusals are unchanged.

## Dynamic runtime

- `ModuleWorkerMcpAnnotations` is now derived from `McpToolAnnotations` (same shape). The contribution
  gateway joins the facade registry through `control.replace`
  (`experiments/dynamic-runtime/mcp-facade-gateway.ts`, checked in `test:dynamic-runtime`).

## Docs and stand

- Rare doc *MCP facade server*, brief cheat sheet section, RPC-AUTH *MCP over HTTP*, DYNAMIC-RUNTIME
  *MCP is optional*. `npm run demo` serves the HTTP facade demo object at `/mcp` with the same token.
- Oracle `oracle/regression/mcp-facade-server.spec.ts`: official SDK client in-process and over real
  HTTP — tools, `this`, read-only refusal, ordering, middleware, errors, limits, strict/names/cycle
  refusals, OpenAPI ↔ MCP parity, abort and progress, resources, list_changed, sessions and auth.

## Repository

- `process-resource` oracle: only the never-ready case keeps the 300 ms startup deadline; the early
  exit and READY cases raced the start of node itself and failed on a loaded Windows host (1 of 3
  isolated runs). Now 15 s for them; 5 of 5 under load.
