# 2.2.3

- Refine safe array-slot replacements in the Store-owned Replay source to exact index patches while
  preserving the public `changedPaths` and `listenStorePatches` whole-array contract. Array length
  changes and whole-array replacement retain the complete-array fallback; injected patch sources
  and Replicated Map keep their declared semantics. The V2 wire format and public API are unchanged.
- Cut the measured 15 MiB Socket.IO Store Replay workload from 292.71 to 32.55 microseconds of CPU
  per write, reduce wire payload by 95.8%, peak heap by 69.2% and event-loop p95 by 97.2%. The
  50 MiB workload now uses 2.45 MiB of WebSocket payload and about 33.47 MiB peak heap while keeping
  one physical envelope per natural Store drain.
- Cover exact slot replacement/growth, structural fallback, mirror convergence and unchanged public
  Store patches. Make the replica-route oracle compare measured routes to each other and allow a
  realistic follower startup window instead of depending on machine-specific timer latency.
