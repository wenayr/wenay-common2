# 2.18.2

- PC1: make peer connection shutdown terminal for publish, publishBatch and signaling;
  recheck origin registration after asynchronous authorization. Preserve other sessions
  of the same account and the host-owned journal lifetime.
- PC2: own callback subscriptions under dynamic RPC paths through the existing callable
  subscription handle. Peer/hub close releases server subscriptions and produces no
  unhandled RPC_ABORT. Dynamic subscriptions are not automatically retried on reconnect.
  Identical dynamic callback subscriptions now share one physical call; each handle owns
  one local consumer. Media stress verifies full delivery and independent window close.
- Reject creation of new peer views after client close; close signal hub registrations.
- H0: document live Store state versus detached nested snapshots across await and the
  required live-state recheck before external destructive operations.
- Add local and real Socket.IO lifecycle regressions; preserve existing public signatures
  and imports (`wenay-common2/peer`, `wenay-common2/rpc`). No new dependency.

SC1/H1/H2 were evaluated against current primitives and remain proposals requiring a
public-contract decision; no new session/resource API or consumer integration is claimed.
See `doc/target/SERVICE-SESSION-OWNERSHIP.md` in the source repository.

Consumers can remove delays/global rejection workarounds added solely for peer shutdown,
and redundant guards for outgoing methods after peer connection close. Keep parent RPC
ownership, domain permissions, room/tab identity and reconnect policy in their owners.
Closing a peer connection is not a revocation of shared journal reads.
