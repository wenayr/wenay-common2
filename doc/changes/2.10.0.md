# 2.10.0

Explicit API boundaries, honest factory inference, and a reproducible release gate.

- Console caller annotations are now explicit opt-in through `wenay-common2/debug-console`;
  `installConsoleCallerAnnotations()` and the compatible lazy `enable()` install once, while
  `disable()` / `enable(false)` leave transparent wrappers in place. Ordinary package imports no
  longer mutate the global console.
- Factory-derived declarations now preserve `clone<T> -> T` and honestly expose
  `ReplayEvent | undefined` when memory, JSONL, or file replay storage has no keyframe.
- Added focused `listen`, `rpc`, `server/fs`, `server/auth`, `server/http`, and `server/webhook`
  package entrypoints while retaining the existing root and server compatibility facades.
- `pack` / `publish` now share a clean-build, full-test, oracle, and dry-pack verification corridor.
- The Node engine floor is now `>=20`; artifact hashing uses global WebCrypto, and CI checks the
  declared Node 20 minimum alongside Node 24 on every pushed branch.
- Dynamic-runtime development proofs now type-check against the current descriptor and Express
  contracts and validate stable MCP resource invariants instead of a mutable document heading.
- Contract and dynamic-host lifecycle facts no longer let a throwing observer reclassify an already
  committed transition; observer errors remain loud asynchronously, sibling observers still receive
  the fact, and failed Store current delivery now removes its just-created subscription.
