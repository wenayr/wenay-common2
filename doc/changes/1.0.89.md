# 1.0.89

- Add `Contract.createContractOffers`, `resolveContractBinding` and `createContractRuntime`: a transport- and frontend-neutral layer that reconciles versioned component demands to reusable local, RPC, worker or downloaded implementation capabilities.
- Add deterministic authority/generation handling, exact-version safety by default, injected compatibility and policy checks, capability filtering, prepare-before-switch atomic bindings and per-call leases for bounded draining.
- Add retry, fallback, active-session failure handling, offer revoke/restore, compatible rollback, required/degraded states, status, history and candidate explanations without moving Store/replay or compilation into the component lifecycle.
- Add local and real Socket.IO/RPC oracles proving Store continuity across implementation replacement, plus an interactive Lab stand for updates, rejected builds, backend version demands, failure and rollback.
