# 2.18.0

- Publish the service definition/schema, safe typed descriptor and browser client; publish authority,
  node, access and REST/OpenAPI composition separately from the Node process host.
- Replace copied scaffold/example implementations with public imports. Extend `identity.me()` with
  views/commands to match live permissions and the consumer's existing adapter.
- Evacuate withdrawn current routes and cancel withdrawn pending routes through the existing
  directory feed. Support graceful IPC shutdown before process exit, including Windows.
- Own HTTP/WS resources, apply one origin policy to HTTP and WebSocket upgrades, await bounded
  mount disposal on close/start failure, and separate host close from optional process signals.
- Add Node process resource with bounded startup/shutdown and shared use in hosting/pizzeria checks.
- Add immutable local binary storage, authorized/limited HTTP router and an existing Artifact port
  adapter; preserve product validation and explicit shared-object retention.
- Verify exact descriptor types, isolated package/browser imports, host/ACL/cleanup races, real
  node crashes/drain/restart, archives/receipts, binary IO and all installed examples.

See [SERVICE-RUNTIME.md](../SERVICE-RUNTIME.md) for exports, migration and ownership boundaries.
Socket.IO/client and Swagger remain optional peers already used by the examples. No React bindings,
consumer-installed package edits or low-level replay/RPC changes. Local verification is Windows;
Linux execution remains with the existing CI matrix and is not claimed as locally tested.
