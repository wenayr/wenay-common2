- Make the peer demo assign stable participant identities per browser tab, select among all online participants, and choose an available port automatically.
- Keep the public HTTPS demo's Socket.IO route upgrade-safe and inject its WebRTC ICE configuration at the application boundary (`DEMO_RTC_ICE_SERVERS`), with public STUN as the zero-config demo baseline and TURN credentials supported for reliable cross-NAT direct routes.
- Order trickled ICE around offer/answer remote descriptions so synchronous and early candidates survive asynchronous WebRTC negotiation instead of causing intermittent direct-route fallback.
- Keep media-relay cleanup independent of its public ACL proxy, so revoking call access before a participant disconnects closes the underlying lines without crashing the demo server.

- Serve the demo directly on a public IP with Let’s Encrypt's 160-hour `shortlived` certificate, correct no-SNI selection, automatic renewal, and the existing sslip.io certificate as a fallback.
- Make `MediaSource.state` a live accessor, and turn the demo's video-call area into a clear local/remote canvas example with 12 fps camera publishing and participant-based calling.
- Add a reactive relay-video room directory to the demo: visible rooms, create/join/leave membership, persistent participant tiles, room camera/screen/audio subscriptions, and separate private calls.
- Make room audio explicit with separate microphone-publishing and room-listening controls, plus live sender and per-participant audio-frame indicators.
- Refactor the media stand into small dependency-injected demo factories for local capture, room membership, room viewers, and private-call viewers while keeping the library API unchanged.
- Let the HTTPS launcher recover after a router reboot forgets its old NAT-PMP lease instead of blocking the next clean restart.
- Refresh the package lockfile version metadata for the release.
