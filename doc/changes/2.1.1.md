# 2.1.1

- Document the declaration-first `.d.ts` workflow: use generated declarations as a compact export
  map, verify runtime behavior in source/tests/docs, and inspect regenerated declaration diffs before
  publishing.
- Expand the shipped code rules for primitive-first layering, intentional multi-level facades,
  inferred types, and closure factories as explicit API builders while retaining classes whose
  semantics are part of the model or contract.
- Split the internal Node HTTPS resource surface into `project`, `caddy`, and `network` facets and
  reuse the existing `sleepAsync` primitive without changing the public HTTPS manager interface.
