# 2.1.2

- Add the per-peer `createMediaRoute` facade with explicit server `relay`, strict `direct`, and
  automatic `best` modes over existing replay connectors, including fallback/retry, policy hooks,
  and one stable consumer line across hand-offs.
- Keep video worker processing capability-selected and enabled by default, retain explicit
  `worker:false`/`worklet:false` opt-outs, and report the selected execution path in media stats.
- Stabilize live PCM calls by aggregating AudioWorklet render quanta into 20ms transport packets and
  preserving a contiguous playback playhead; rebuild the configurable jitter buffer only after a
  real underrun and expose underrun counts in player statistics.
